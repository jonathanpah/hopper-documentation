# hopper-documentation

[English](hopper-documentation-en/README.md) | [Português (Brasil)](hopper-documentation-pt-br/README.md)

A plugin for Claude Code and Codex that records conversation handoffs, so another person or AI can continue the work, on macOS and Linux.

Um plugin para Claude Code e Codex que registra handoffs de conversas, para que outra pessoa ou IA possa continuar o trabalho, em macOS e Linux.

Choose one language and follow its installation instructions: clone this repository once and add the chosen language folder as a local plugin marketplace. Both versions install as `hopper-documentation`; install only one of them in each tool.

Escolha um idioma e siga as instruções de instalação dele: clone este repositório uma vez e adicione a pasta do idioma escolhido como catálogo (marketplace) local de plugins. As duas versões se instalam como `hopper-documentation`; instale só uma delas em cada ferramenta.

Each release includes both languages. The code and behavior are the same; the documentation, the content rules and the handoff headings follow the language.

Cada release inclui os dois idiomas. O código e o comportamento são os mesmos; a documentação, as regras de conteúdo e os títulos dos handoffs seguem o idioma.
